# Financial Performance Dashboard (Excel + Power BI)

## Project Overview

This project analyzes financial sales data using Excel and Power BI to provide business insights through interactive dashboards and visualizations.

The dashboard helps stakeholders track key performance indicators (KPIs), identify profitable products and segments, monitor country-wise performance, and analyze sales trends over time.

## Tools Used

* Microsoft Excel
* Power BI
* Pivot Tables
* Data Cleaning & Transformation
* Data Visualization

## Key KPIs

* Total Sales: **118.73 Million**
* Total Profit: **16.89 Million**
* Units Sold: **1.13 Million**
* Profit Margin: **14.23%**

## Dashboard Features

* Sales Trend Analysis by Month
* Country-wise Sales and Profit Performance
* Product Performance Analysis
* Segment-wise Profitability Analysis
* Discount Band Analysis
* Interactive Filters and Slicers
* KPI Cards for Business Metrics

## Key Insights

* Highest Sales Country: **United States of America**
* Highest Profit Product: **Paseo**
* Most Profitable Segment: **Government**
* Lowest Profit Discount Band: **High**
* Best Sales Month: **July**

## Business Questions Answered

1. Which country generates the highest sales?
2. Which product contributes the most profit?
3. Which customer segment is the most profitable?
4. How do sales change across different months?
5. What impact do discount bands have on profitability?
